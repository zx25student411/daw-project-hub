Un espacio para aprender a desarrollar, publicar y mantener aplicaciones web, conociendo las fases de su desarrollo y despliegue.

Desarrollo web y colaboración

Desarrollo web

El desarrollo web permite crear páginas y aplicaciones utilizando tecnologías como HTML y CSS.

Despliegue

El despliegue consiste en poner una aplicación web a disposición de los usuarios en un entorno donde pueda ejecutarse.

Colaboración

El trabajo colaborativo permite que varias personas desarrollen un proyecto de forma organizada mediante herramientas como Git y GitHub.
